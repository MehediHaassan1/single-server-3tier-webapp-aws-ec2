## Subnets

### What is Subnet?
A subnet is a segmented range of IP addresses inside a VPC used to organize resources.

### What I created

- Public Subnet
  - CIDR: 10.0.0.0/20

- Public Subnet 2
  - CIDR: 10.0.16.0/20

- Private Subnet 1
  - CIDR: 10.0.128.0/20

- Private Subnet 2
  - CIDR: 10.0.144.0/20

### Why Subnets?
- Separate public and private resources
- Improve security
- Better traffic control
